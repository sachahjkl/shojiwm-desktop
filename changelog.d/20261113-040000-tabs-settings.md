**Window tabs never take windows that draw their own title bar**: Firefox, GNOME programs and other windows with their own title bar can no longer be dropped on a window as a tab, or take one, as their title bar ended up under the tabs. Other windows still group as tabs. The Control Panel's Taskbar and Start menu page has two choices: "Group any windows as tabs" and "Open new terminal windows as tabs", both on by default.
