**A NixOS module for the whole desktop, and a way to try it**: on NixOS, `nixosModules.default` with `services.shojiwm-desktop.enable` installs the session: ShojiWM, the configuration, the shell, the portal, the icon theme and the log-on screen's module. `nix run github:sachahjkl/shojiwm-desktop` runs the desktop in a window of the current session, without changing `~/.config`.
