How shojiwm-desktop was made, what it uses and under which licences, the trademarks it names, and what this site does with your data.

An independent implementation

shojiwm-desktop is an independent, clean-room implementation. The window frames, the shell and the Control Panel were written from scratch: the frames as a compositor configuration for ShojiWM, in TypeScript, and the shell and the Control Panel in Rust, on AntiWebUI.

No code, image, icon, font, sound or other file from Microsoft Windows is copied, embedded or decompiled. The desktop does not need any file from Windows to run.

The Aero theme's look was reconstructed by visual observation only. Public screenshots of Windows 7 programs, from Wikimedia Commons, were measured pixel by pixel. Every size, colour and transparency is written down, with the picture it came from, in docs/aero-measurements.md. Those screenshots are not in the repository. Every element was then drawn again: the frames as shaders, the buttons and symbols as SVG files.

The Kernel theme is an original design.
