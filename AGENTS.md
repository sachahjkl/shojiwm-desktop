# shojiwm-desktop

## Changelog

`CHANGELOG.md` follows Keep a Changelog and semantic versioning. Do not edit it by hand: write each change a user can see as one fragment in `changelog.d/`, in the same commit as the change. `changelog.d/README.md` gives the format.

## Roadmap

`ROADMAP.md` holds the planned work: `# Roadmap`, then `## Now`, `## Next` and `## Later`, each a list. Each entry starts with a short bold summary, then one or two sentences on what it gives the user. No dates, no metadata. When a work is done, remove its entry in the same commit as its changelog fragment.

## Intent

This project follows https://srcmd.org, with the Markdown in `src/md`. Read `src/md/README.md` first. Change the intent first, then the code and the tests, in the same commit.
